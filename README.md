# 🚐 نظام إدارة توريد وتأجير السيارات والميكروباصات

نظام ويب بسيط وعملي بيساعدك تعرف في أي وقت:
كل رحلة دخلت كام — صرفنا كام — كسبنا كام — مين لسه ليه فلوس.

---

## تشغيل النظام

### المتطلبات
- Python 3.10 أو أحدث
- اتصال بالإنترنت للمرة الأولى فقط (تحميل خطوط Google Fonts)

### خطوات التشغيل

```bash
# 1) تثبيت المكتبات (مرة واحدة بس)
pip install -r requirements.txt

# 2) تشغيل السيرفر
python3 app.py
```

بعد كده افتح المتصفح وروح على:

```
http://127.0.0.1:5000
```

## النسخ الاحتياطي

### طريقة 1: من النظام
افتح صفحة **"نسخة احتياطية"** من القائمة → اضغط **"إنشاء نسخة احتياطية الآن"**

### طريقة 2: يدويًا
انسخ ملف `data/company_data.xlsx` في أي مكان تاني على الجهاز.

النسخ الاحتياطية بتتحفظ تلقائيًا في مجلد `backups/` باسم مثل:
```
backup_2026-09-07_14-30-00.xlsx
```

## كيفية إضافة عميل

1. من القائمة الجانبية اضغط **"العملاء"**
2. اضغط **"+ إضافة عميل"**
3. اكتب اسم العميل (مطلوب) ورقم الهاتف (اختياري)
4. اضغط **"حفظ"**

---

## كيفية إضافة عربية

1. من القائمة اضغط **"العربيات"**
2. اضغط **"+ إضافة عربية"**
3. ادخل رقم اللوحة أو اسم/كود العربية
4. حدد نوع الملكية: **ملك الشركة** أو **عربية حرة**
5. لو عربية حرة، اختار صاحب العربية من القائمة
   *(لازم تضيف صاحب العربية الأول من صفحة "أصحاب العربيات")*
6. اضغط **"حفظ"**

---

## كيفية إضافة سواق

1. من القائمة اضغط **"السواقين"**
2. اضغط **"+ إضافة سواق"**
3. ادخل الاسم (مطلوب) ورقم الهاتف (اختياري)
4. اضغط **"حفظ"**

---

## كيفية تسجيل رحلة

1. من القائمة اضغط **"الرحلات"** → **"+ إضافة رحلة"**
   *(أو من الزر الكبير في الصفحة الرئيسية)*
2. ادخل:
   - التاريخ
   - العميل
   - العربية *(النظام بيعرف تلقائيًا لو العربية حرة ويظهر حقل أجرة صاحب العربية)*
   - السواق
   - سعر الرحلة من العميل
   - أجرة صاحب العربية (لو عربية حرة)
   - أجر السواق
   - لترات السولار وسعر اللتر *(النظام بيحسب إجمالي السولار تلقائيًا)*
   - الكارتة *(تقدر تختار من مسار محفوظ أو تكتب رقم يدوي)*
   - العمولة (اختياري — معلوماتي فقط، مش بيتحسب مرتين)
3. شاشة الحساب التلقائي بتوضح التكلفة وصافي الربح قبل ما تحفظ
4. اضغط **"حفظ الرحلة"**

**معادلة الحساب:**
```
صافي ربح الرحلة = سعر الرحلة من العميل
                  − (السولار + الكارتة + أجر السواق + أجرة صاحب العربية)
```

## كيفية تسجيل تحصيل من عميل

1. اضغط **"العملاء"** من القائمة
2. اضغط على اسم العميل
3. في صفحة العميل، اكتب المبلغ والتاريخ وطريقة الدفع
4. اضغط **"تسجيل تحصيل من العميل"**

النظام بيحسب تلقائيًا:
- إجمالي المستحق على العميل
- اللي اتحصّل
- المتبقي

---

## كيفية استخراج التقارير

1. من القائمة اضغط **"التقارير"**
2. اختار التقرير اللي تريده:
   - تقرير الرحلات — تقرير الأرباح — تقرير العربيات
   - تقرير العملاء — تقرير أصحاب العربيات — تقرير السواقين
   - تقرير السولار — تقرير الصيانة — تقرير المصروفات — تقرير التحصيل
3. اضغط **"⬇ تصدير Excel"** لتحميل التقرير كملف إكسل

## الحسابات — ملخص المعادلات

| البند | المعادلة |
|-------|----------|
| تكلفة السولار | اللترات × سعر اللتر |
| إجمالي تكلفة الرحلة | سولار + كارتة + أجر سواق + أجرة صاحب عربية |
| صافي ربح الرحلة | سعر الرحلة − إجمالي التكلفة |
| ربح العربية | مجموع أرباح رحلاتها − مصاريف الصيانة |
| مستحق العميل | مجموع قيمة رحلاته − ما اتحصّل منه |
| مستحق صاحب العربية | مجموع أجراته − ما اتدفعله |
| مستحق السواق | مجموع أجره − ما اتدفعله |

**ملحوظة عن العمولة:** العمولة حقل معلوماتي بس — بيوضح إن جزء من صافي الربح هو نصيب الشركة كسمسرة. مش بتتضاف ولا بتتطرح في الحسابات عشان ما تتحسبش مرتين.

## الأمان

- ملف الإكسل مش متاح مباشرة عبر المتصفح
- كل المدخلات بتتتحقق منها قبل الحفظ
- الحذف بيكون "ناعم" (soft delete) — البيانات مش بتتمسح فعلًا من الإكسل
- النظام لا يسمح بتنفيذ أوامر من المستخدم
